# NS3

In NS3, a network node is annotated as a `Node` object. Such object can hold a
list of `NetDevice` (represent a [Network Layer](202206131702.md) to device
interface), which is connected to other nodes through channel. It can also hold
a list of `Application` which represent userspace traffic generation
applications like SUMO. Nodes are automatically added to `NodeList`.

There is an object `NodeContainer` that can be used to help track of nodes by
adding or creating them.

`NetDevice`, as stated above, represents a network layer to device interface,
that defines API which IP and [Application Layer](202206131856.md) need to
access to manage an instance of a network device layer. It doesn't support
[MAC](202206131651.md)-level multicast but can be customised to do so. It is
analogous to the interface just above the `dev_queue_xmit()` on Linux, i.e.,
IP packet is fully constructed with destination MAC address already selected.

Channel, as represented by the object `Channel`, is a logical path over which
information flows. It can be [wired](202210111820.md) or
[wireless](202303301607.md).
