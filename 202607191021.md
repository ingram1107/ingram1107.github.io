# MySQL

MySQL is an integrated, transaction safe, and ACID-compliant
[Database-Management System (DBMS)](202302101137.md). It has high performance
and scalability, self-healing replication clusters, online schema changes,
performance schema, relational tables, and schema-less JSON documents.

It is platform independent and has big data interoperability (with Hadoop and
Cassandra).

**Note**: In MySQL, database and schema is used interchangeably.
