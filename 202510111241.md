# Rust Async

`async` will result in a [Rust](202410042152.md) function, a closure, or a block
into [Rust Future](202510111235.md). The following shows an example of `async`
usage.

```rust
async fn example() -> i32 {
    let x = async {
        return 5;
    };

    x.await
}
```
