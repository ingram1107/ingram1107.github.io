# Commvault Oracle Database Full In-Place Restore

When doing a full in-place [Restore](202608121923.md), we have to make 3
assumptions:
1. All [database logs](202607160007.md), [Control
 Files](202607152300.md), and [SP files](202607152311.md) are lost
2. The direcotry structure is recreated for data files (note that
 [RMAN](202607180001.md) cannot create them by themselves)
3. The [Oracle instance](202607182224.md) is started from within RMAN
 using `rman target /`

We have to bring the database into a [Special Started State](202608121953.md)
since it involves the restoration of SP files. Enter the command `startup force
nomount` within RMAN.

Then, review the backup history to identify the job that is the closest to the
desired point-in-time. From there, identify the control file backup piece handle
(which is a file name) then perform "Browse and restore".

Confirm that the database is in [Started state](202607181358.md) and check the
*Restore SP File* option. Check *Switch Database Mode* for restore if the
database was not previously reported in a correct state.

Check the option *Set [Oracle DBID](202608121955.md)* when there is no
[Recovery Catalogue](202607180014.md) and there is a need to restore the
control file or SP file from [auto backup](202608122010.md), or there are
multiple databases exist in recovery catalogue and there is a need to restore
the control file.

Checking the option *Switch DD Mode* will restart the database to Started or
Mounted state. Problems will arise if there were mistakes from the customer in
[TNS records](202607182138.md) where we might shut down and override the wrong
database.

At recovery tab, choose *Current Time* if the most recent archive files is still
available on the destination within the destination server. This could happen
when there is server failure on the data volume but the archive log volume is
intact. Backing up with this option may include the archive log files that are
not yet backed up.

Choose *Latest SCN Number* to only include backed up archive logs.

Choose *Point in Time* to replay partial amount of archive logs.
