# Commvault Oracle Database PDB Clone

[Commvault](202607181352.md) software can duplicate [CDB](202607152338.md)
and [PDBs](202607152342.md) to an auxiliary instance in a staging path. It
will stage the CDB, unplug the PDBs from the staged CDB, then plugs them into
the new CDB.

If there is no [Recovery Catalogue](202607180014.md), do not use `/` (like in
[Local Connect](202607182141.md)) and [TNS string](202607182138.md).

To perform PDB clone, we require the `sysdba` privilege level.

**Note**: Staging path must have enough space for the clone.

**Note**: If Auto Storage Management (ASM) is used, the path cannot be browsed
for setting paths during PDB clone configuration.

Choose *Latest [SCN](202608102126.md) number* for
[recovery](202608121940.md).
