# MySQL Permissions

To show the permissions granted to a specific user, we can run the
[MySQL](202607191021.md) command `select Show_db_priv, Super_priv,
Reload_priv, Select_priv, Lock_tables_priv, Process_priv, Execute_priv,
Show_view_priv from user where user = 'backupser';` or `SHOW GRANTS FOR
'backupuser'@'localhost'`;
