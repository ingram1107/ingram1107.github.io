# SCN in Commvault Oracle iDA

Each completed job will store [SCN](202608102126.md) associated with it at the
end of the job which [Commvault](202607181352.md) also stores them.

If any SCN is required, it must be provided by the DBA.

The field Last SCN can be treated as the last consistent state of the database.
