# Commvault MySQL Restore Procedure

[Commvault MySQL Restore](202607212231.md) starts by dropping the database.
The process is logged in `MySqlRestore.log`. Then, data and log files restore
will be performed, which is recorded in `ClRestore.log`. Commvault will export
[Binary Log](202607191049.md) to SQL file by running the command
`mysqlbinlog.exe`, before applying the SQL to the database using `mysql`
command.

SQL file is applied to replay the actions included in binary log into the data
files.
