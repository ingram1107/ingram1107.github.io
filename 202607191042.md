# MySQL Connection

To connect to `mysql`, `mysqldump`, `mysqlshow`, or `mysqladmin`, we have to run
the below command or other commands with similar format:

```
mysql -u {usr} -p {dbname}
```
or
```
mysql -h {host} -u {user} -p {dbname}
```
- -P: specifies the port to use
- --protocol: we can choose the option TCP (for local or remote), SOCKET (for
  local and Unix only), PIPE (for local and Windows only), or MEMORY (shared
  memory, for local and Windows only).
