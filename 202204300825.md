# Ansible Plugins

Ansible Plugins allow a #[playbook](202204272036.md) to execute extra
functionalities or change behaviours without support from Ansible architecture.
It is recommended to write out the fully qualified [collection](202204300837.md)
name (FQCN) to avoid potential namespace conflict. The format of a plugin's
(FQCN) can be like `ansible.builtin.file`, where `ansible` is the distributor's
name, `builtin` is the collection's name, and `file` is the plugin called.

Filter Plugin is a kind of Ansible Plugins that could be used to change the
output format for [variable](202205042134.md)# of a task to JSON, YAML or CSV.
It uses Jinja2 filter for example `{{ variable | trim }}`.
