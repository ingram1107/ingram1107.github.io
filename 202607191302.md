# Commvault Supported MySQL Storage Engines

Commvault supports following storage engines for [MySQL](202607191021.md):
- [InnoDB](202607191637.md) (default)
- [MyISAM](202607191640.md)
- [TokuDB](202607191641.md)
- [Infobright](202607191647.md)
- [XtraDB](202607191648.md)
