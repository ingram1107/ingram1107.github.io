# RMAN repository

[RMAN](202607180001.md) repository is a collecting of **metadata about target
database** RMAN uses for backup, recovery, and maintenance.

The metadata are always stored in [Control File](202607152300.md), and the
version of that metadata will become the authoritative record of RMAN backup of
the database. Thus, the *protection of the control file* is vital.

RMAN repository stores a record of all data files and backups taken, so it knows
what backup exists, when and how many times its files have been backed up. This
allows users to back up without knowing the underlying files.
