# Anycast Rendezvous Point (Anycast-RP)

Anycast-RP is a [Protocol](202209302229.md) based on Multicast Source
Discovery Protocol (MSDP) that provides load balancing,
[Redundancy](202607261831.md), and [Fault Tolerance](202607261841.md) by
assigning the same IP address to multiple RPs within a [PIM
sparse](202302201639.md) mode network multicast domain.
