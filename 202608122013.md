# Commvault Oracle Database PDB In-Place Restore

In [PDB](202607152342.md) in-place [restore](202608121923.md), there may have
the need to restore the [Control File](202607152300.md) if the [Recovery
Catalogue](202607180014.md) is not used, unless the restore point-in-time is
*within the last 7 days*.

The most reliable way to do this is by piece handle. Select the *Reset Logs* to
None.

Check *Switch Database Mode* option. Alternatively, we can manually set the
[Database States](202607181358.md) in Started or Mounted.

There is no need to restore the control file as it is shared across the
[CDB](202607152338.md).
