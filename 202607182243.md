# Commvault Oracle Database Offline Backup

Offline backup in [subclient backup](202607182229.md) option has a unique
feature compare to other three options, i.e., the need to run the script
*"lights Out"* to put the [Oracle Database](202607152254.md) into [Mounted
state](202607181358.md) at the start of the offline backup. It is to make sure
that the database is in a consistent state. After completed the backup, the
script will bring the database online again.

By default, the script has 3 retry chances to put the database into the desired
state with 70 seconds waiting in between attempts.

Offline backup requires the database to be in Mounted state with the
`NOARCHIVELOG` mod enabled.
