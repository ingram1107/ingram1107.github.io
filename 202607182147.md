# Oracle Database SID

`Oracle_SID` can be configured by souring the script file `oraenv` with the
command `. oraenv` or via manual configuration (`export ORACLE_SID=sid` in Unix
or `$env:ORACLE_SID="sid"` in Windows).

The [query](202607172338.md) `select instance_name, status from v$instance;` not
only can be used to check the [Oracle Database States](202607181358.md) (from
the `status` column), but also useful for checking `ORACLE_SID` from the
`instance_name` column.

You may also found `Oracle_SID` in [Oratab](202607181355.md).
