# Commvault Oracle Database ArchiveLog Subclient Backup

ArchiveLog subclient backup includes [Control File](202607152300.md) backup,
while disables **Switch Current Log** and [data files (BFS)](202608102101.md)
option.

Archive log backup is necessary for any data restore or recovery to achieve
consistency.

It is recommended to have a regular backup of archive log, that is to have
*several runs per data backup*. Having a regular archive log backup allows the
ability to recovery to the closest point before disaster. Another benefit of it
is to make room for the database, though it often leads to missing archive log.

The option will also delete the archive log before the server is running out of
space. If we want to remove the logs that were not previously deleted instead,
check the **Archive Delete All** option.

It is recommended to also enable **Backup [SP File](202607152311.md)**.
