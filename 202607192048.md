# MySQL Backup and Restore Permissions

To grant backup permissions in [MySQL](202607191021.md), run the following
commands:

```sql
CREATE USER 'backupuser'@'localhost' IDENTIFIED BY 'password';
GRANT SHOW DATABASES, SUPER, RELOAD, SELECT, LOCK TABLES, PROCESS, EXECUTE, SHOW VIEW ON *.* to 'backupuser'@'localhost';
FLUSH PRIVILEGES;
```

To grant restore permissions in MySQL, run the following commands:

```sql
CREATE USER 'restoreuser'@'localhost' IDENTIFIED BY 'password';
GRANT ALL PRIVILEGES ON *.* to 'restoreuser'@'localhost';
FLUSH PRIVILEGES;
```

Note that `FLUSH PRIVILGES` is necessary to reload the `GRANT` table in order to
apply the effect without restarting MySQL service.
