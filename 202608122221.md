# Commvault Oracle Database Restore Crosses Incarnation

If a [Data Restore](202608121923.md) crosses an
[Incarnation](202608102123.md), it will have a job pending reason. From there,
find the error listed at the bottom of the [RMAN log](202607181325.md).

It is recommended to connect to a [Recovery Catalogue](202607180014.md) if there
is one as the [Control File](202607152300.md) will have an accurate history of
the incarnations.

Then run the command `list incarnation of database {target-database}`. From the
command's output, which will print a table, take the number from the incarnation
key column (abbreviated as `Inc Key`) and enter the restore options.
