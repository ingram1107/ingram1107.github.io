# RMAN crosscheck

`crosscheck` is a [Recovery Manager (RMAN)](202607180001.md) command used to
fetch accurate information for all archive logs in the [RMAN
repository](202607180011.md).

By default, it marks the missing [archive log(s)](202607160007.md) as
unavailable instead of deleting it. Every time the command runs, it will check
the archive log's status again.
