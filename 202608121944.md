# Oracle Database Data Restore vs Data Recovery

In [Data Restore](202608121923.md), the [archive log](202607160007.md) is
placed on disk. In [Data Recovery](202608121940.md), the archive logs,
instead, is applied to the database. We can see the difference clearly when
executing [RMAN](202607180001.md) commands.

## RMAN restore

```
RMAN> restore database;
RMAN> restore data file #;
RMAN> restore controlfile from autobackup;
RMAN> restore (archivelog from logseq = 100 until logseq = 150 thread 1);
```

## RMAN recovery

```
RMAN> recover database;
RMAN> recover datafile #;
RMAN> recover databaes until scn #########;
RMAN> recover database until time = "TO_DATE('01/11/2017 06:50:00', 'MM/DD/YYYY HH24:MI:SS')";
```

See more in [System Change Number (SCN)](202608102126.md).
