# System Change Number (SCN)

SCN is an internal timestamp, generated by the internal clock in [Oracle
database](202608102123.md), to track and process transaction.

Data can be recovered accordingly to the specified SCN, which is recommended
when comparing to point-in-time restore as it is more precise.

For Commvault, see more in [SCN in Commvault Oracle iDA](202608102130.md).
