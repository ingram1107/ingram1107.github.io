# MySQL Workbench

MySQL Workbench is a GUI interface to [MySQL](202607191021.md).

Under *Management* tab, we could look into server status, client connections,
uses and privileges, status and system variables, and data export or import.

Under *Instance* tab, we could initiate startup or shutdown and look into server
logs (error logs and [Slow Log](202607191057.md)) and options file
(configuration).

Under *Performance* tab, we can view the dashboard and read performance reports.

Under *Schemas* tab, we can utilise schema explorer and query information.
