# Binary Log

Binary logs (`binlog.######`) in [MySQL](202607191021.md) contain events
that describe data changes, such as table creation operation, data changes on
table etc. They also contain events for statements that potentially could have
made changes on the database and information about how long each statement took
that updated data.

Binary log is required for some data recovery operation. After the backup has
been restored, the events recorded in the binary log will be re-executed, which
brings the database up to the data from the point of the backup. Therefore, it
is necessary to back up binary logs.

To be able to back up binary logs, we have to enable the option `log-bin`.

To verify whether binary logging is enabled, run `show variables like
"%log_bin%"` and see if `log_bin` variable has the value of "ON". We can check
further with the MySQL command `show binary logs;` to check if a binary log is
created.
