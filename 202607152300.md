# Control File

Control file in [Oracle Database](202607152254.md) stores metadata for
database structure, name, associated files, redoes log information, timestamp of
database creation, current log sequence, and checkpoint information. It is
shared among [PDB(s)](202607152342.md) within a single
[CDB](202607152338.md). And since it only knows about the metadata of the data
files, it **does not know the actual content** stored in those files.

It usually comes with a file name like `control01.ctl`. In out-of-place or
[Cross-Server](202607181344.md) restore, it is also known as the `datafile 1`.

Note that control file, like any other [Oracle files](202607152257.md) such as
data files and [`spfile`](202607152311.md), cannot be opened directly,
otherwise it will become corrupted and cannot be read by the database
afterwards. It is recommended to open the control file first before reading it.

Control file has a limit of retention up to *7 days* of activity. To extend
that, we can create [recovery catalogue(s)](202607180014.md), which can be defined to store a
longer history.
