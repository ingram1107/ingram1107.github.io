# Oracle Control File

Control file in [Oracle Database](202607152254.md) stores metadata for
database structure, name, associated files, redoes log information, timestamp of
database creation, current log sequence, and checkpoint information. It is
shared among [PDB(s)](202607152342.md) within a single
[CDB](202607152338.md).

It usually comes with a file name like `control01.ctl`. Note that control
file, like any other [Oracle files](202607152257.md) such as data files and
[`spfile`](202607152311.md), cannot be opened directly, otherwise it will
become corrupted and cannot be read by the database afterwards. It is
recommended to open the control file first before reading it.
