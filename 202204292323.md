# Red Hat Ansible Automation Platform

Red Hat Ansible Automation Platform provides [Ansible](202204272021.md)#
automation, [cloud services](202210012158.md), and content in
[Ansible Collection](202204300837.md)# which includes infrastructure like
[Linux](202204081225.md)#, cloud or container technologies
([Docker](202110201636.md)# and [Kubernetes](202201291535.md)#), network (CISCO)
and security including devices and how they fit in the environment. There are
on-premise tools to help us on centralising delivery of automation content,
managing automation tasks, and scaling distribution of automaton execution.
Cloud services are also provided, with the purpose of helping discover certified
Ansible content, facilitate team collaboration, and provide operational
analytics to automation mixed, hybrid environment.

There are several components within the platform including [Automation Controller](202205251152.md)#.

It mostly interacts with upstream [core](202204272021.md)#. For command line
tools, it provides #[Ansible Content Navigator](202204300954.md).

**Note**: Red Hat Ansible Automation Platform provides the Ansible Core in
`ansible-core` coupled with `ee-minimal-rhe18` and `ee-supported-rhe18`.
