# Oracle Database Data Recovery

Data recovery of [Oracle Database](202607152254.md) is done through
[Recovery Manager (RMAN)](202607180001.md). It applies [archive
logs](202607160007.md) or incremental backups to restore data files. Archive log
is applied to the database as part of the job.

See the [difference with data restore](202608121944.md).
