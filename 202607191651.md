Run the command `show engines;` to show what is the default storage engine
being used. Another way to do it is by running the query `SELECT TABLE_NAME,
ENGINE FROM information_schema.TABLES WHERE TABLE_SCHEMA = 'DB1';`.

To show the configured engine for a database, first enter into the database
(`use DB1;`) then run the command `show table status;`.
