# Failover

Failover, as defined by Cisco, is a process performed by failed primary
component moves to a backup component. Essentially, it is to switch over
automatically to a [redundant](202607261831.md) or standby computer server,
system, hardware component or network upon the failure or abnormal termination
of the previously active application, server, system, hardware component, or
network in a computer network.

Note that sometimes failover and switchover may be used interchangeably, but
traditionally the process of switchover is done with human intervention in
contrast to failover, which should be done automatically.

When the previously failed primary component has been brought up, it is eligible
for [failback process](202607261839.md).
