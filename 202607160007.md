# Oracle Database Transaction Log

Transaction log has 2 states: **online redo log** and **archive log**. The
former is for the logs that are in use, the latter is for the logs that are
completed.

It is used to apply changes to the [Oracle Database](202607152254.md).
Therefore, if the database does not write transaction logs or online redo logs,
the database will simply go down.

Archive logs are needed to achieve consistency. Thus, it is important to back up
and delete the archive logs on a regular schedule to ensure there is enough room
for the database. This may be the main cause for the missing of archive logs.
