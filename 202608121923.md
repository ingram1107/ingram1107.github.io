# Oracle Database Data Restore

To perform a successful data restore, [Oracle Database](202607152254.md) must
be in [Mounted state](202607181358.md). If the restore includes [Control
File](202607152300.md), then the database must be in *Started state*. If it
involves [SP file](202607152311.md), alone or along with control file, the
database has to be in a [Special Started State](202608121953.md) (trigger
through [Recovery Manager (RMAN)](202607180001.md)).

The reason the control file restore has to be in Started state is because of the
acquired lock by the database when it is in Open or Mounted state. Therefore, no
one has the access to replace the control file.

Before doing data restore, we have to ensure that the destination exists in both
Oracle and Commvault since RMAN **cannot create directories** by itself.

In RMAN data store, the [archive log](202607160007.md) is placed on disk. It is
the job of DBA to apply the log and bring the database back online. It will
restore datafiles, [tablespaces](202607152324.md), [Control
Files](202607152300.md), [server parameter files](202607152311.md) (SP files),
and archive logs.

See the [difference with data recovery](202608121944.md).
