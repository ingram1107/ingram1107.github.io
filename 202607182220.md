# Oracle Database Primary Group

To find the primary group of [Oracle Database](202607152254.md), we should run the
command `ps -ef | grep pmon` and then `id {user}`.

It is important to do so as we have to grant access to Oracle to the files
resided in [Commvault](202607181352.md) directories. If no group is specified,
the permissions will be set to everyone can read, write, and execute the
Commvault program directories.
