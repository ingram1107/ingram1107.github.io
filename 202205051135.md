# Automation Hub

Automation Hub is a platform for [sharing contents](202205051149.md)# coming
from Red Hat certified partner, community and within the organisation (published
but private). It can be self-hosted in an on-premise server or
[cloud](202210012158.md)#. It pulls the [Ansible Collection](202204300837.md)#
using [automation controller](202205251152.md)#.
