To design a [High Availability](../202607261046.md) architecture, Oracle
recommends three key elements:
- **[Redundancy](../202607261831.md)**
    - multiple components can perform the same task
    - to eliminate single point of failure
- **Monitoring**
    - check whether a component is working properly
- **[Failover](../202607261833.md)**
    - the process by which a secondary component becomes primary when
      the primary component fails
