# Oracle Tablespace

Tablespace is a logical unit that stores data, in contrast to data files that
store data in a physical disk. Tablespace would be stored as data files in the
format of `.dbf`.

Tablespaces in [Oracle Database](202607152254.md) include:
- **SYSTEM**
- **SYSAUX**
- **UNDO**
- **TEMP**
- **USERS**

*SYSTEM* tablespace stores built-in functions, packages, data directory,
schema/views, custom definitions, users, and permissions.

*SYSAUX* tablespace is used by Oracle streams, Oracle texts, and AWR (Automatic
Workload Repository), which collects, processes, and maintains performance
statistics for database.

*UNDO* tablespace stores previous [DML](202302171843.md) values kept for
rollback or read consistent data.

*TEMP* stores temporary data generation when processing SQL statement such as
query and index builds.

*USERS* stoers permanent user objects and data.

Every database should have temporary tablespace (*TEMP*) assigned to users as
their temporary tablespace. The same goes to user tablespace (*USERS*).
