# Recovery Manager (RMAN)

RMAN is a utility that is responsible for **backing up and recovering** [Oracle Database](202607152254.md),
providing **block-level corruption detection** during backup and restoration,
and optimising **performance and space consumption** during backup with file
multiplexing and backup set compression.

**Note**: [Commvault Oracle iDA](202607182207.md) relies on RMAN on backup and
recovery operations.

RMAN can conduct all necessary backup recovery operations with just [Control File](202607152300.md)
to store [RMAN repository](202607180011.md) information. It reads control file
for the *metadata* about the data files, but it does not fully aware of the data
files, especially their contents.

When writing backups, RMAN groups data files and archive logs into
[sets](202608102112.md) (with user-customised size). After the sets are
written, they are stored in [Backup Pieces](202608102115.md), which can be
treated as files. Each backup piece has a **piece handle**, which can be
understood as the name of the backup piece, with the job ID as its prefix.

RMAN *cannot create directories or folders*, therefore we have to make sure that
all path to be written to must exist. Additionally, if RMAN fails to create
file, check if the path exists.

RMAN [logs](202607180018.md) the backup jobs in `backup.out` with the rest
of the files on Windows or under a subdirectory on Unix.

The following sections involve lots of RMAN commands for basic backup commands.
See more in [RMAN Script](202607181325.md).

## Connecting and Authorising with Database

RMAN can connect to the database with [TNS Connect](202607182138.md),
[Local Connect](202607182141.md) and [EZConnect](202607182153.md).

To connect through TNS Connect, run the following command:
- `rman target user/password@service`
- `rman target user/password@service catalog user/password@service` (to access
  [Recovery Catalogue](202607180014.md))

To connect through Local Connect, run the following command:
- `rman target /`
- `rman target / catalog user/password@service` (to access [Recovery
  Catalogue](202607180014.md))

To connect through EZConnect, run the following command:
- `rman target user/password@hostname` (assume `hostname` is the same as the
  service name)
- `rman target user/password@hostname/service`
- `rman target user/password@hostname:port/service` (if the port number is not
  *1521*)

## RMAN Restore

See data restore and comparison with recovery for further details:

```
restore database;
restore data file #;
restore controlfile from autobackup;
restore (archivelog from logseq = 100 until logseq = 150 thread 1);
```

## RMAN Recovery

See data recovery and comparison with restore for further details:

```
recover database;
recover datafile #;
recover database until scn ########;
recover database until time = "TO_DATE('01/11/2017 06:50:00', 'MM/DD/YYYY HH24:MI:SS')";
```

## Restore to Disk

See restore to disk for further details:

```
configure channel device type 'sbt_tap' PARMS="SBT_LIBRARY=/opt/commvault/Base/libobk.so,ENV=(BACKUP_DIR=/opt/oracle/dbs/Restore_To_Disk/162252,CV_media=FILE)";
catalog device type 'sbt_tape' backuppiece 'backuppiecename1', 'backuppiecename2';
show all;
run {
allocate channel ch1 type 'sbt_tape';
allocate channel ch2 type 'sbt_tape';
restore database;
recover database;
sql "alter database open";
}
```
