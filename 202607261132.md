# Zero Downtime System

Zero downtime system is highly related to [Fault Tolerance](202607261841.md).
It is a system where [modelling and simulation](202607261657.md) indicates
mean time between failures significantly exceed the period of time between
planned maintenance, upgrade events, or system lifetime. Such system involves
massive redundancy.

Example of zero downtime system are:
- some types of aircraft
- most kinds of common satellites
- [Global Positioning System (GPS)](202305282217.md)
