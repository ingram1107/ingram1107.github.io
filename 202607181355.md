# Oratab

`/etc/oratab` is a UNIX-applicable-only configuration file that acts as a
**registry** on what *database and software versions* are installed on the
machine and to figure out which *instances to be started and stopped*. It is
created upon installation.

Oratab contains fields, each with the following format:

```
$ORACLE_SID:$ORACLE_HOME:Y/N
```

**Note**: `Y/N` indicates the option for autostart. Y allows autostart, N
disable autostart.
