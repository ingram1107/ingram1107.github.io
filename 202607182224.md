# Commvault Oracle Database Instance Discovery

[Oracle Database](202607152254.md) instances will be automatically created
when:
- Discovery initiated every 24 hours, which can be modified by adjusting
  the automatic discovery additional setting
- Restart the communication services of the client
- Instances are defined in Oracle [Oratab](202607181355.md) file
- Non-clustered single instance that is in Started, Mounted, or Open
  [states](202607181358.md)
- Oracle RAC instances that are in Mounted or Open state
