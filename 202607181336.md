# In-Place RMAN Log

Within the in-place [RMAN](202607180001.md) log, we may have some peek on the
information which can be useful during troubleshooting.

`sql 'alter database mount'` changes the database to [Mounted state](202607181358.md).

`alter database open reset logs` restarts the log sequence and generally
results in a new incarnation being created.
