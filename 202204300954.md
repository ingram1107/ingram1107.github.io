# Ansible Content Navigator

`ansible-navigator` is a #[Red Hat Ansible Automation Platform](202204292323.md)
command line interface (CLI) tool to view or monitor various
#[Ansible](202204272021.md) information. It can run
[playbooks](202204272036.md)# and [Execution Environment (EE)](202204300942.md)#.
It is an enhanced version of `ansible-playbook` which unlike the latter, can run
EE.

If running without any command or options, `ansible-navigator` will open up a
terminal user interface (TUI) to monitor various information on all hosts.

Executing the command `run {playbook}` will run the
[playbook](202204272036.md)# on the managed nodes. With `--check` option,
Ansible navigator will dry run the specified playbook which means that the
configuration will not impose on the managed nodes.

We can run `inventory` command to show the [inventory](202204272043.md)#
information from all hosts. To list the information from only a specified host
or group, pass it in as an argument to the command as in `inventory
{host/group}`. For more verbosity, use the option `--list`, where host
information will be listed in JSON format. If verbosity is not desired, use the
option `--graph` instead, which will simply display all hosts in `all`
group. This option also accepts a parameter to show hosts in group (`--graph
{group}`). `-i` option is used to specify the pathway to inventory file(s).
The option `--host` shows variables associated with the specific inventory
host or group within the inventory.

The configuration file `ansible-navigator.yml` or `ansible-navigator.json`
is used to change default options for `ansible-navigator` command. The file
defined in shell environment `ANSIBLE_NAVIGATOR_CONFIG` takes first
precedence, then the local project's, and lastly the user's home's
(`$HOME/.ansible-navigator.yml`). The following example shows possible
configuration option for `ansible-navigator`.

```yaml
---
ansible-navigator:
  execution-environment:
    # container image name to use for automation execution environment (EE)
    image: utility.lab.example.com/ee-supported-rhel8:latest
    # define a policy that pull the container image when it is missing
    pull:
      policy: missing
  playbook-artifact:
    enable: false
  mode: stdout
```

~The global configuration stores in `$HOME/.ansible-navigator.yml`.~ We can
access the logs in `$HOME/.ansible-navigator/logs/`.
