# Cross-Server RMAN Log

Within the cross-server (out-of-place) [RMAN](202607180001.md) log, we can
have some peek to understand some issues that may arise, which can be helpful in
troubleshooting.

It usually starts with the line `restore controlfile from '...'` like
[In-Place](202607181336.md) restore unless it is using catalogue connect.

In cross-server restore, it will try to change the [database state](202607181358.md)
into Mounted state just like in in-place restore. In contrast to the in-place
restore, cross-server restore will run data restore by executing the command
`set newname for datafile ... to ...`. This is the Redirect feature provided by
[Commvault](202607181352.md) to change the data file path.

**Note**: `datafile 1` generally means the [Control File](202607152300.md).

`switch datafile all` will cause just the restored data file to become the
active data files for this database.
