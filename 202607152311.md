# Oracle Parameter Files

Parameter files stores [database](202607152254.md) initialisation parameters.

There are two types of files where the parameter would be store, one is `pfile`,
and another is `spfile`.

The former comes with a plain text configuration, usually with a name similar to
`pfile.ora` or `init$ORACLE_SID.ora`. It is a legacy file for storing the
parameters, and it will not be backed up by RMAN.

`spfile` is in binary form, which comes with a file name like
`spfile$ORACLE_SID.ora`. It cannot be opened directly, just like other
[Oracle files](202607152257.md) such as [Control File](202607152300.md) and
data files, otherwise it will be corrupted and cannot be read by the database
afterwards. `spfile` can be backed up by RMAN. It is recommended to copy it
first before reading it.
