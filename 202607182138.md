# TNS Connect

TNS Connect relies on **TNS string** for [Connection and Authorisation](202607181414.md)
with Oracle. It has the following format:

```
user/password@service
```

Service name is translated by TNS to hostname and port name, where the request
is directed tot he associated database.

Run the following commands to connect to [SQL Plus](202607172338.md) or
[Recovery Manager (RMAN)](202607180001.md):
- `sqlplus user/password@service as sysdba`
- `sqlplus user/password@service as sysbackup` (after Oracle 12c)
- `rman target user/password@service`
- `rman target user/password@service catalog user/password@service` (access
  [Recovery Catalogue](202607180014.md))

`TNS_ADMIN` folder is default to `$ORACLE_HOME/network/admin`
