# Oracle Database Incarnation

Incarnation in [Oracle Database](202607152254.md) can be understood as the
**timeline of the database**. It is often created when a point-in-time restore
ran.

It starts with sequence 1. A restore database request will create a second
incarnation, which is generally transparent by itself. However, if the restore
needs to be run in the future before the point-in-time, the incarnation will
reset to 1 as part of the restore.
