# Data Files (BFS)

Data files (BFS) in [Commvault Oracle iDA](202607182207.md) represents how
many data files are included in each [Recovery Manager
(RMAN)](202607180001.md) backup set.

The *smaller* the value of data files (BFS), the *higher the overhead*, then it
is compensated with *better backup reusability*. To better understand what is at
stake, let say if the backup is interrupted, RMAN will continue from the latest
completed set. Smaller value of data files (BFS) will have **smaller [Backup
Sets](202608102112.md)**, which also means more checkpoints than larger sets.
Small backup set deduplicate better which could potentially result in faster
restores depending on the nature of restore.
