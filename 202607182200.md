# Oracle Database Listener Registration

Listener registration only concerns about [TNS Connect](202607182138.md) and
[EZConnect](202607182153.md), as [Local Connect](202607182141.md) bypass
listener. There are two ways of registration:
- **Static**: create instance records manually in `listerner.ora`
- **Dynamic**: automatic at instance startup

Dynamic registration requires less manual maintenance, but the services will
disappear when instances are shutdown. Thus, the database can only be accessed
via [Local Connect](202607182141.md). There would be some troubles on data
restore and offline backup.

Static instance is available regardless of the [instance state](202607181358.md),
which allows TNS Connect or EZConnect to shut down the database

We may use the program `lsnrctrl` to control the listeners, which has the
following commands:
- `status`
- `start`
- `stop`
