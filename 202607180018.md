# RMAN Log Directory

RMAN log directory resides at:
- `/opt/commvault/iDataAgent/jobResults/CV_JobResults/2/0/JOBID#/` on Unix
- `\Program Files\Commvault\ContentStore\iDataAgent\JobResults\CV_JobResults\2\0\JOBID#\`
  on Windows

When viewing the logs, pay attention whether [RMAN](202607180001.md) has named
Commvault system and its version when its vendor library is being used.
