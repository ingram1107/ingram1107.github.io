# Maximum Number of Open Files

A larger maximum number of open files is better provided the system has
sufficient resources to accommodate the loads. Its value **should not exeed
BFS** value (both [Data Files (BFS)](202608102101.md) and [Archive Files
(BFS)](202608102106.md)) as it cannot open more files than it can include in the
current [Backup Set](202608102112.md).
