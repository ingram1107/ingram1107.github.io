# Undo Files

Undo file (`undo_###`) is the default undo [Tablespaces](202607191058.md)
created when the [MySQL](202607191021.md) instances initialised. It provides a
location to rollback segments that must exist before MySQL statement can be
accepted.

It contains undo logs, which is a collection of undo log records that contain
information on how to undo latest change by a transaction to a cluster index
record.
