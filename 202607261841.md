# **Fault Tolerance**

Fault tolerance is the system ability to keep operating without interruption
even if multiple hardware or software components fail. It aims for [Zero
Downtime](202607261132.md) instead of [High Availability's](202607261046.md)
minimal downtime. This may require the physical component replication, which
does not prioritise the performance unlike in HA system.
