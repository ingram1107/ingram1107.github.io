# Commvault MySQL Best Practices

Best practices on setting up [MySQL iDA](202607191025.md) configuration is to
configure separate subclients (see below), automatic instance discovery, cluster
configuration, no [MySQL](202607191021.md) NDB cluster support, and enabled
[binary logging](202607191049.md) (`log-bin`).

When separating subclients, Commvault recommends allocating **few small ones for
one single subclient** and dedicating a **single subclient for a large
database**. This will prevent a scenario where repeated success backup occurs
due to restart cause by smaller databases.

Ensure that the customer is working on the correct MySQL instance since
customers can have more than one instance running on a single machine.

It is best to suggest the customer have their DBA takes the following steps and
to ensure that the actions are performed on the correct instance. Then, verify
binary logging is enabled once the steps have been taken.
1. Identify configuration file.
2. Add `log-bin` parameter.
3. Restart services.
4. Verify binary logging.

For Windows:
-

- Run `Get-WmiObject win32_service | ?{$_.Name -like '*mysql*'} | select Name,
  PathName | fl` to identify the configuration file for the instance.
- Under `[mysqld]` section, set `log-bin=mysql-bin.log`.
- Run `.\mysqladmin.exe -u root -p shutdown`, `get-service *mysql*` (for
  verification), then `net start MySQL80`, to restart the service.

**Note**: When there are multiple configuration files, it means there are
multiple MySQL instances. In that case, we need customer instruction on which
instance to be modified.

For Linux:
-

- Run `which mysqld`, `{path-to-mysqld} --verbose --help | grep -A 1 "Default
  options"` to identify the configuration file for the instance.
- Under `[mysqld]` section, set `log-bin=mysql-bin.log`.
- Run `mysqladmin -u root -p shutdown`, `systemctl start mysql` to restart the
  service, the command `systemctl status mysql` could be used to verify its
  status.

To verify whether binary logging is enabled, run `show variables like
"%log_bin%"` and see if `log_bin` variable has the value of "ON". We can check
further with the MySQL command `show binary logs;` to check if a binary log is
created.
