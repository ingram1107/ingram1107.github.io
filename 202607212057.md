# mysqldump

The command `mysqldump` is usually used for [MySQL](202607191021.md)
database backup. Well known parameters used are shown below:
- `--default-file={}`: specify the configuration file that contains
  `mysqldump` command options, which can be useful to pass along the password
- `--single-transaction`: force discard of the default `LOCK TABLE`
  option, allow consistent backup of tables having transactional [MySQL
  Storage Engine](202607191651.md).
- `--flush-logs`: force MySQL to start a new log file before the dump
  operation begin
- `--master-data={2/1}` (TODO): force a comment added to the output,
  include the binary log coordinate (file name and position) of the dump data
- `--create-options {-B}`: include all MySQL specific table options within
  the `create table` statement
- `--default-character-set={}` set the character set
- `--routines`: automatically include restore procedures and functions within
  backup data
- `--max_allowed_packet={}`: set the maximum size of the buffer for the
  client-server communication
- `-u {}`: specify the user to carry out the dump operation
- `--socket={}`: specify what socket to use (or port in Windows)
- `--databases {}`: specify which database to be backed up/protected
