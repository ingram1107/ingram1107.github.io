# Commvault Oracle Database Restore Sequence

[Commvault](202607181352.md) will first bring back the [SP
file](202607152311.md) (system parameter file) for database initialisation.
Then, it will restore the [Control File](202607152300.md) (especially the
**second control file**, which is both data files and [archive
logs](202607160007.md) aware). During this stage, the control file allows Oracle
to make aware of the [Database State](202607181358.md). After that, it continues
by restoring the data files based on the metadata from the control file. Last
but not least, the archive logs are restored accordingly, which could be later
be [applied](202608121940.md) to the database.
