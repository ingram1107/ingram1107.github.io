# Rust Future

[Rust](202410042152.md) Future represents an asynchronous computation obtained
by the use of [`async`](202510111241.md). The object might store a value that haven't finished
its computation. The poll method, provided by the [trait](202204061235.md), will
attempt to resolve the final value, and it would not be blocked if the value
isn't ready. Instead, it is scheduled by the register for wakeup using a `Waker`
struct.
