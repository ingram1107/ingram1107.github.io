# MySQL InnoDB Files

Below we discussed [InnoDB](202607191637.md) files and directory stored in
[MySQL Data Directory](202607191047.md).

`#ib_####_#.dblwr` is a double write buffer for InnoDB. It is a storage area
where InnoDB write pages flushed from the buffer pool before writing into the
proper position in InnoDB data files. InnoDB can find a good copy of the page
from double write buffer during crash recovery.

`ib_buffer_pool` is a file used to avoid length warm up period after restarting
[MySQL](202607191021.md) server. It is done by saving the buffer pool state at
the server shutdown and restore the buffer pool to the same state at the server
startup.

`ib_logfile#` is an InnoDB redo log file. It records InnoDB changes to the
tablespaces, which is important for performance and recovery.

`innodb_temp/` directory stores temporary user created table and internal
temporal tables created by the InnoDB optimiser.

Another InnoDB file worth mentioning is the shared tablespace which is stored in
`ibdata#`.
