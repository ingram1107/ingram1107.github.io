# Commvault Oracle Database Selective Online Full (SOF)

SOF is an online database full plus log backup option available in [Commvault
Oracle Database Subclient Backup Options](202607182229.md). It is the default
option for default [Oracle Database](202607152254.md) subclient and newly installed clients.

All data and logs are stored into data storage policy instead of having separate
policies for data and logs, unlike [online backup](202607182236.md). This
makes the backup qualified for extended retention or selective copy. Subclient
for SOF can be used for incremental backup (standard increments), but it will
**disqualify** them for extended retention or selective copy.

It is required for the database to be [Online](202607181358.md) and with
`ARCHIVELOG` mod enabled.
