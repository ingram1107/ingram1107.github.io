# Commvault Oracle Database Restore to Disk

Restore to disk is an application-free data restore operation without relying on
[Recovery Manager (RMAN)](202607180001.md). For this to be successful, the
destination client must have **File System** package installed and the account
chosen must have the right privilege on the restore path. Essentially, we are
performing a file-system restore. However, since it is a file-system restore, we
do not actually restore the database itself. For that, we still have to utilise
RMAN commands.

After the restore, we have to catalogue the backup pieces within RMAN before
using RMAN restore. It is to make RMAN recognise these data files. We first have
to connect to the target database, then configure the channel device. After the
configuration is verified, we catalogue the backup pieces. After that, we
restore the database. The following commands guide us on this.

```
RMAN> configure channel device type 'sbt_tap' PARMS="SBT_LIBRARY=/opt/commvault/Base/libobk.so,ENV=(BACKUP_DIR=/opt/oracle/dbs/Restore_To_Disk/162252,CV_media=FILE)";
RMAN> catalog device type 'sbt_tape' backuppiece 'backuppiecename1', 'backuppiecename2';
RMAN> show all;
RMAN> run {
        allocate channel ch1 type 'sbt_tape';
        allocate channel ch2 type 'sbt_tape';
        restore database;
        recover database;
        sql "alter database open";
        }
```
