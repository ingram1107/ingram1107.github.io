# Commvault Oracle Database Subclient Backup Options

There are four subclient backup options available in
[Commvault](202607181352.md) Command Center for [Oracle
Database](202607152254.md) subclient:
- **[Selective Online Full (SOF)](202607182238.md)**: online database full plus log backup
- **[Online Backup](202607182236.md)**: online backup full plus log backup
- **Online Subset Backup**: specify backup of subset of database objects
- **[Offline Backup](202607182243.md)**

*SOF*, *Online Backup*, and *Online Subset Backup* requires the database to be
online and the `ARCHIVELOG` mod enabled. They also have the *Switch Current Log*
option enabled.

In contrast to the above three online backup options, offline backup requires
the database to be in [Mounted state](202607181358.md) with the
`NOARCHIVELOG` mod enabled. Since the database is in a consistent state, there
is no need to back up archive logs hence the enabled `NOARCHIVELOG`.

All options by default have the [Control File](202607152300.md) configured to
be backed up and the option *Backup [SP File](202607152311.md)* disabled.
