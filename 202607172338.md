# SQL Plus

SQL Plus is an [Oracle Database](202607152254.md) utility used to query and
manage Oracle.

## Connecting and Authorising with Database

SQL Plus can connect to the database through [TNS Connect](202607182138.md) or
[Local Connect](202607182141.md).

To connect through TNS Connect, run the following command:
- `sqlplus user/password@servce as sysdba`
- `sqlplus user/password@service as sysbackup` (after Oracle 12c)

To connect through Local Connect, run the following command:
- `sqlplus / as sysdba`
- `sqlplus / as sysbackup` (after Oracle 12c)

## Checking and Manipulating Database States

SQL Plus is capable of checking and manipulating [Oracle Database States](202607181358.md).

Run the query `select instance_name, status from v$instance;` to check the
states of the database (from the `status` column) and `ORACLE_SID` (from the
`instance_name` column). See more in [Oracle SID](202607182147.md).

Another way to check the status of the database is by executing the query
`archive log list`.

There are four commands to manipulate the database states correspondingly:
- `startup` (Open)
- `startup nomount` (Started)
- `startup mount`
- `shutdown`

## Finding Control File Backup

We can find the [Oracle Control File](202607152300.md) backup using the *job ID*
with the following queries.

```sql
alter session set nls_date_format = 'YYYY-MM-DD HH24:MI:SS';
column handle format A50;
select handle, start_time from v$backup_piece_details where bs_key in (select btype_key from v$backup_controlfile_details) and handle like '60688%');
```
