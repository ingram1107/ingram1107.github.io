# Local Connect

Local connect can only be used by logging into the server where the
[Oracle Database](202607152254.md) instance is running. This
[connection](202607181414.md) method can be disabled by
[Commvault](202607181352.md) iDA.

To be eligible for local connect in Unix environment, log in as the *user that
owns the instance*. In Windows environment, log in to the *user that is in the
OraDBA group*.

There is no need to specify the service name, only a slash '/' is needed, as it
solely relies on [Oracle SID](202607182147.md).

Run the following commands to locally connect to [SQL Plus](202607172338.md) or
[Recovery Manager (RMAN)](202607180001.md):
- `sqlplus / as sysdba`
- `sqlplus / as sysbackup` (after Oracle 12c)
- `rman target /`
- `rman target / catalog user/password@service` (for [Recovery
  Catalogue](202607180014.md))

**Note**: Local connect cannot be directly used on the recovery catalogue
itself.

Local connect bypasses [listener](202607182200.md).
