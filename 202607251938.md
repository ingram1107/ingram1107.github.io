# Commvault MySQL Command Line Backup

Before backing up using SBT, ensure the agent can back up too. Ensure the
command line storage policy on the properties of MySQL instance is defined.
`LD_LIBRARY_PATH` has to be [Commvault's home directory](202607212224.md).
Then, back up by running the command `/usr/bin/mysqlbackup --defaults-file={}
-u {} -p --socket={} --sbt-lib-path={ (CVHome/libobk.so)/(orasbt.dll) }
--sbt-database-name={instance name} --backup-image={} --backup-dir {}
backup-to-image`.

**Note**: To look up the image name, run the command `/opt/commvault/Base/getbackupList
-jobid {} -outfile {} -dbjob`.
