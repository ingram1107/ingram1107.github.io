# EZConnect

EZConnect can connect remote services with required Database Agent (DBA) to
maintain [TNS](202607182138.md) across their environment. However, this
[connection](202607181414.md) method can only be used on
[RMAN](202607180001.md).

Run the following commands to connect to RMAN:
- `rman target user/password@hostname` (assuming `hostname` is the service name)
- `rman target user/password@hostname/service`
- `rman target user/password@hostname:port/service` (if the port number is not
  1521)
