# Commvault MySQL Command Line Restore

Before running a command line restore, make sure that the restore operation can
be carried out by Command Center and CommCell Console. Ensure that
`LD_LIBRARY_PATH` is [Commvault Home Directory](202607212224.md).

First, look up the image name by running the command
`/opt/commvault/Base/getbackupList -jobid {} -outfile {} -dbjob`.

Extract the file and the incremental backup image by running the command
`/usr/bin/mysqlbackup --back-dir=/db/extract
--backup-image="{incremental-img-name}" --sbt-lib-path={sbt_path}
--sbt-database-name={dbname} image-to-backup-dir`.

Run the command `/usr/bin/mysqlbackup --backup-dir=/db/extract apply-log`
which apply logs to update [InnoDB](202607191637.md) tables. These logs
include the data changes while the backup is running.

Apply incremental backups which updates the backup data by running the command
`/usr/bin/mysqlbackup --incremental-backup-dir={should be the same path during
the extraction} --backup-dir={} apply-incremental-backup`.

Stop the [MySQL](202607191021.md) service with the command `mysqladmin -u root
-p shutdown`.

Rename or delete the data directory by running the command `cp -R -p
/var/lib/mysql /data/backup`, then run `rm -R /var/lib/mysql`.

Finally, do the copy-back, with the command `/usr/bin/mysqlbackup
--defaults-file={config file} --backup-dir={} --datadir=/var/lib/mysql
copy-back`.
