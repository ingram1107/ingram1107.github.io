# MySQL Data Directory

[MySQL's](202607191021.md) data directory is located at `/var/lib/mysql`,
which stores [binary logs](202607191049.md) (`binlog.######`), [binary log
index](202607191053.md) (`binlog.index`), [database schema
directory](202607191054.md), certificate files (`.pem`), [InnoDB
files](202607191100.md), and [undo files](202607191104.md) (`undo_###`).

If there is a dedicated mount point for MySQL, we have to verify the data
directory is a subdirectory on the mount point.
