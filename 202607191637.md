# InnoDB

InnoDB is a transaction-safe, ACID-compliant [MySQL Storage
Engine](202607191651.md). It has commit, rollback, and crash recovery
capability. It provides roll-level logging and [Oracle-style](202607152254.md)
consistent non-logging reads plus multiuser concurrency and performance.
