# Oracle Database Online Backup

[Oracle Database](202607152254.md) does not [quiesce](202607182204.md) database
for online backup. Thus, online backups are fuzzy or inconsistent as it is being
backup. In Oracle, the database must be consistent, so fuzzy backup is not
useful on its own.

Instead, we need [archive logs](202607160007.md) to restore from an online
backup to reach consistent state. Therefore, it is utmost important to back up
archive logs as well.

See [Commvault Oracle Database Backup Sequence](202607182213.md) to see how this could be done.
