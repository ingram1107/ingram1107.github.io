# Commvault MySQL Restore

Commvault supports three restore operations on [MySQL](202607191021.md)
instance:
- **In-place**
- **Out-of-place**
- **Restore to disk**

For command line restore, see [Commvault MySQL Command Line
Restore](202607251945.md).

When running a restore on [MySQL](202607191021.md), ensure [MySQL System
Database](202607191044.md) is running.

When restoring master server, stop any replication process between master and
slaves. After the restore, make sure replication is online on the proxy server.
Verify the restore by running the command `show databases;`.

When doing a cross-machine (out-of-place) restore of the system database, ensure
that the source and destination server has MySQL instances created in CommCell
Console using the same SA (TODO) username and password.
