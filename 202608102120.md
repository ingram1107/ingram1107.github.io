# Commvault Oracle Database Standard Backup Options

There are 3 standard backup options for [Oracle Database](202607152254.md):
- **[Full](202608122235.md)**: backs up both data and
  [Logs](202607160007.md) based on configured [backup
  method](202607182229.md) (selective online/online/offline)
- **Incremental**: backs up everything since last full or incremental
  backup
- **Cumulative**: backs up everything since last full backup, similar to
  differential backup
