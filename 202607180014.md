# Recovery Catalogue

Recovery catalogue is a repository of [RMAN](202607180001.md) metadata stored in
Oracle schema. It can be viewed as a long-life [Control File](202607152300.md)
if one wants to extend the retention over 7-day limits to store a longer
history.

It can be its own database running in parallel with the Oracle database.
