# Ansible Execution Environment (EE)

EE is a #[container](202202211633.md) image, commonly referred to as Universal
Base Image, built by Ansible Builder that incorporates
[collections](202204300837.md)#, libraries and [core](202204272021.md)# (any
version of it). It replaces the Python virtual environment (`virtualenv`). It
could be run by #[content navigator](202204300954.md).
